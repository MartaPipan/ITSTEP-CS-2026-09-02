# Періодична таблиця хімічних елементів

## Опис проєкту

Цей проєкт являє собою вебсторінку з **періодичною системою хімічних елементів**.

## Мета проєкту 
створити зрозумілу та структуровану HTML-сторінку, на якій у зручному вигляді представлена інформація про хімічні елементи.

Для кожного елемента відображаються:
 атомний номер;
 хімічний символ;
 назва елемента українською мовою;
 електронна конфігурація за електронними шарами;
 відносна атомна маса;
 хімічна категорія;
 агрегатний стан.

## Структура хімічного елемента

Кожен елемент представлений окремою клітинкою.

Наприклад:

```text
┌─────────────────────┐
│ 19        2 8 8 1   │
│                     │
│         K           │
│       Калій         │
│       39.0983       │
└─────────────────────┘
```

У клітинці:

* **19** — атомний номер;
* **2 8 8 1** — розподіл електронів за оболонками;
* **K** — хімічний символ;
* **Калій** — назва елемента;
* **39.0983** — атомна маса.

У HTML ці дані розділені на окремі елементи з класами `number`, `electrons`, `symbol`, `name` та `mass`.

## Категорії елементів

Для кращої візуалізації використовуються різні CSS-класи для категорій:

 `col-alkali-metal` — лужні метали;
 `col-alkaline-earth-metal` — лужноземельні метали;
 `col-transition-metal` — перехідні метали;
 `col-post-transition-metal` — метали після переходу;
 `col-metalloid` — напівметали;
 `col-non-metal` — неметали;
 `col-noble-gas` — благородні гази;
 `lanthanide` — лантаноїди;
 `actinide` — актиноїди;
 `col-unknown` — елементи з невідомою категорією.


##  Агрегатний стан

У проєкті також використовується кольорове позначення агрегатного стану:

 **Тверде тіло**
 **Газ**
 **Рідина**
 **Невідомо**

Наприклад, для брому використовується клас `liquid`, а для криптону — `gas`.

##  Структура таблиці

Періодична система представлена у вигляді HTML-таблиці з **18 групами** та **7 періодами**.

Заголовки груп пронумеровані від 1 до 18.

Для правильного розташування елементів використовуються порожні клітинки (`class="empty"`), які зберігають структуру періодичної системи.
